# 📚 BuscaLivro

Aplicação web para pesquisa de livros utilizando a API da [Open Library](https://openlibrary.org/developers/api).

O projeto permite pesquisar livros por título e autor, visualizar os resultados em cards e consultar informações adicionais de cada livro.

## ✨ Funcionalidades

- 🔎 Pesquisa de livros por título
- ✍️ Pesquisa por autor
- 📚 Pesquisa combinando título e autor
- 📄 Paginação dos resultados
- ➕ Botão "Buscar mais" para carregar novos resultados
- 🖼️ Exibição das capas dos livros
- 📖 Modal com informações sobre o projeto
- 📱 Layout responsivo utilizando Bootstrap

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Bootstrap Icons
- Open Library Search API

## 🚀 Como executar

Não é necessário instalar dependências.

Basta clonar o projeto:
```
git clone https://github.com/hick-hpe/buscalivro.git
```

Entre na pasta:
```
cd buscalivro
```

Depois, abra o arquivo `index.html` no navegador.
